# Historical routing compatibility

This path is retained for tools or notes that referenced the earlier routing guide. Schema4.0 supersedes those routing rules; use [../TAXONOMY.md](../TAXONOMY.md) and [output-schema.md](output-schema.md).

The useful historical lesson is to inspect each trial's actual artifacts and source version. Do not copy one task-level diagnosis across different agents or attempts. Different trials can contain different bugs, and a single assertion can expose a consequential error.

The former automatic routes are retired: citation presence did not establish mathematical correctness; a conventional default did not settle every ambiguous task; exact pins did not authorize hidden RNG recipes; and mixed task/agent defects were possible. Historical labels and calibration statistics should remain versioned evidence, not silently rewritten as current judgments.
